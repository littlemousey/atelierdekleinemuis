Ik zal je heel erg missen \
Zal ik je ooit weer zien? \
Stiekem hoop ik het

Want ondanks dat ik weet \
Dat ik onze tijd samen moet koesteren \
Niet boos moet zijn \
Op dat het is afgelopen \
Maar dankbaar om wat er was \
Toch kan ik het gevoel niet ontlopen

Dat ik je meer had kunnen geven \
Meer met je had willen delen \
Het gevoel dat dat nooit meer kan \
Voelt toch onverdraaglijk

Heb ik je goed verzorgd? \
En zal je op mij wachten? \
Waarom maak ik mij zorgen \
Om antwoorden op al die vragen \
Die ik misschien nooit krijg \
Onder de regenboogbrug
